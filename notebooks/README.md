# Notebooks

Use notebooks for exploration and documented experiments. Keep reusable data collection, validation, and modelling logic in `src/bharatair/`.

Suggested sequence:
1. Station and sensor coverage audit.
2. Exploratory analysis of selected PM2.5 sensors.
3. Data-quality and missingness analysis.
4. Baseline forecasting experiments.

Record the data period, sensor IDs, filtering decisions, split dates, and random seeds in each experiment.
